# ゴルフスコア管理

ブラウザで動くゴルフのスコア管理アプリです。

- 18ホールのスコア入力（◎○−△□ のタップ入力、トリプル以上は数字で入力）
- OUT／IN スタートの切り替え
- 同伴者のスコア入力（最大4人）
- 同じコース・同じホールの過去のベスト／ワースト／平均の表示（先頭プレーヤーのスコアで集計）
- 履歴、成績（平均・ベスト・パー別平均・結果の割合・スコア推移）
- JSON でのバックアップと読み込み

スコアは使っている人のブラウザ（localStorage）にだけ保存され、サーバーには送られません。
ブラウザのデータを消すと記録も消えるので、ときどき「成績」タブからバックアップを書き出してください。

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます。確認用サーバーを使う場合は次のとおりです。

```
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 8081
```
